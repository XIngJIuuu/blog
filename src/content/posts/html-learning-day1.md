## 一、双标签与单标签

HTML 标签分为两种：

- **双标签**：有开始和结束，例如 `<strong>文字</strong>`
- **单标签**：没有结束标签，例如 `<br>`、`<hr>`

```html
<strong>文字内容 双标签 strong</strong>
<br>
单标签 hr 单横线
<br>
br 换行
<hr>
```

- `<strong>`：加粗，属于双标签
- `<br>`：换行，属于单标签
- `<hr>`：水平分割线，属于单标签

## 二、标题标签 h1 ~ h6

标题从 `h1` 到 `h6` 字号逐渐变小，每个标题都是单行块级元素。

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
```

注意事项：

- `h1` 一个页面建议只使用一次，`h2` ~ `h6` 没有次数限制
- 标题标签是**容器级标签**，里面可以放其他内容

## 三、段落标签 p

```html
<p>段落标签1111</p>
<p>段落标签2222</p>
```

`p` 是文本级标签，通常放文字、图片、表单元素等，不建议在 `p` 里嵌套标题或另一个 `p`。

## 四、文本格式化标签

| 效果 | 标签 |
|---|---|
| 加粗 | `<strong>` / `<b>` |
| 倾斜 | `<em>` / `<i>` |
| 下划线 | `<ins>` / `<u>` |
| 删除线 | `<del>` / `<s>` |

```html
<strong>加粗strong</strong>
<b>加粗b</b>
<em>倾斜em</em>
<i>倾斜i</i>
<ins>下划线ins</ins>
<u>下划线u</u>
<del>删除线del</del>
<s>删除线s</s>
```

## 五、图片标签 img

```html
<img src="./ENDFIELD_SHARE_1769271575.png" alt="图片描述" title="终末地图片" width="300" height="200">
```

`img` 常用属性：

| 属性 | 说明 |
|---|---|
| `src` | 图片地址 |
| `alt` | 图片加载失败时显示的替代文本 |
| `title` | 鼠标悬停时显示的提示文本 |
| `width` / `height` | 图片宽度 / 高度，默认等比例缩放 |

路径写法：

- `./`：当前文件夹
- `../`：上一级文件夹
- `../../`：上上级文件夹

## 六、超链接 a

```html
<a href="https://www.baidu.com">跳转到百度</a>
```

`a` 是文本级标签，常用于页面跳转、锚点跳转等，后续 Day 2 会继续展开超链接的各种属性。

## 七、HTML 注释

注释不会显示在页面上，方便开发者记录说明：

```html
<!-- 给用户看的 -->
<!-- <strong>niceee</strong> -->
```
